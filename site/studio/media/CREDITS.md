The audio package includes edited excerpts. **Voice**: LibriVox 17.55–29.55 s; **music**: 0–18 s; **café**: 4–22 s; **typing**: 0–6 s.

The original files are fetched from these exact URLs only by the opt-in GitHub Actions media build. The uploaded release artifacts are derived, resampled and encoded **48 kHz stereo MP3** for broad browser decoding. Each output has its own SHA-256 in `SHA256SUMS`; the browser verifies bytes before decoding. No general URL fetcher, scraper or external media proxy is embedded in the studio.

**Important:** A public-domain label does not guarantee public-domain status in every jurisdiction. Contributors are responsible for checking their intended use. Any public distribution of a mix containing the CC BY keyboard recording must retain the required author attribution and license link. The studio includes these credits in the show-note export; no automated copyright clearance is claimed.
